# В детстве я боялась, что меня украдут телепузики

Лонгрид, перенесённый с Тильды на чистые HTML, CSS и JavaScript. Никаких библиотек и сборки: папку можно положить на любой хостинг как есть.

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Все 23 сцены, слои и тексты. У каждого слоя координаты из макета шириной 1200 |
| `css/style.css` | Раскладка, масштабирование под ширину окна, зацикленные анимации |
| `js/main.js` | Анимации по скроллу (в том числе «прилипание» слоёв), запуск циклов, появление |
| `assets/` | Бегущая строка в конце (`ticker.png`) |
| `fonts/` | Inter Display Medium (только латиница и кириллица) для текста с обводкой |
| `images.txt` | Список картинок: имя файла и адрес на Тильде |
| `download-images.sh`, `download-images.bat` | Скачивают картинки в `images/` |

## Первый шаг: скачать картинки

Картинок в архиве нет, они пока лежат на серверах Тильды. Их нужно один раз забрать, пока страница на Тильде существует.

- **macOS / Linux.** Открой Терминал, перейди в папку проекта (`cd` и перетащи папку в окно), затем выполни `sh download-images.sh`.
- **Windows.** Дважды кликни `download-images.bat`.

В папке `images/` должно появиться 82 файла. После этого открой `index.html` в браузере.

## Публикация

Залей содержимое папки на хостинг. Все пути относительные, поэтому страница работает и в корне сайта, и в подпапке, например `твой-сайт.ru/tv2000/`. Для GitHub Pages достаточно положить папку в репозиторий сайта.

## Как править

- Передвинуть или изменить размер слоя: `--x`, `--y`, `--w` у нужного `<div class="el">` в `index.html`. Значения в пикселях макета.
- Высота и фон сцены: `--h` и `--bg` у `<section class="scene">`.
- Анимации по скроллу: атрибут `data-scroll`. Формат описан в начале `js/main.js`. Плавность, с которой они догоняют прокрутку, задаёт `SMOOTHING` там же (секунды, 0 выключает).
- Появление слоёв при прокрутке (`data-in`): длительность, сдвиг и плавность общие для всех, это `--in-dur`, `--in-dist`, `--in-ease` в `css/style.css`.
- Зацикленные анимации: переменные `--to-x`, `--to-y`, `--to-scale`, `--to-rotate`, `--dur` у `<div class="fx">`.
- Текст с обводкой: блок `<div class="caption">` в `index.html`, абзацы в `<p>`, строки разбиты через `<br>`. Цвет подложки у блока задаётся так: `<div class="caption" style="--halo-color:#0a4b9e">`. Кегль, межбуквенное расстояние, толщина обводки, размер и цвет жёлтой подложки, размытие слоя задаются переменными `--size`, `--tracking`, `--stroke`, `--halo`, `--halo-color`, `--blur` в `.caption` в `css/style.css`. Их можно переопределить и для одного блока: `<div class="caption" style="--size:20">`.
- Плавные переходы между сценами (`.seam`) размывают только фон сцены — её первый слой с классом `bg`. Чтобы слой тоже размывался, добавь ему `bg`. Градиент из «союзмультфильма» в пейзаж с планетой — `.fade-to-next`, цвет `--fade-color` в `css/style.css`.
- Мобильная версия: на узких экранах тексты с обводкой увеличиваются до кегля около 15 px (`MOBILE_TEXT_PX` в `js/main.js`), раздвигаются, если наезжают друг на друга, а сцены при нужде удлиняются. Остальное масштабируется пропорционально, как на компьютере.
- Шум поверх страницы: блок `.noise` в `css/style.css`.

## Чем отличается от версии на Тильде

- На Тильде страница была собрана только под ширину от 1200 пикселей, на экранах уже этого вёрстка обрезалась, а анимации отключались. Здесь макет целиком пропорционально сжимается под любую ширину, анимации работают везде.
- Убраны плашка «Made on Tilda», счётчик Тильды и её favicon.
- Если в системе включено «уменьшить движение», зацикленные анимации и появления отключаются.
